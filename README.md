<h1>Beluga v0.1.0</h1>
<p>Beluga is a wrapper for three.js that is meant to make it easier to develop browser-based games without a 3rd-party tool like unity. v0.1.0 is a pre-release meant to showcase the base server-side contructs that will be expanded into the frontend in the alpha.

Beluga relies on preset protocols ([here](docs/Protocols.md "Protocols")) in order to function. The alpha release will have both client-side protocols and the ability to implement custom protocols.</p>

<h2>Installing</h2>
```npm install beluga-engine```
